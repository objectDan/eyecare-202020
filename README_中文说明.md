## 为什么叫 20-20-20

“20-20-20”来自常见的护眼建议：每工作 20 分钟，看向 20 英尺（约 6 米）外的地方，持续至少 20 秒。程序默认工作 20 分钟、休息 20 秒，所以叫 20-20-20 护眼提醒器。

## 运行环境

推荐 Windows 10 或 Windows 11。

程序只使用 Python 标准库和 Windows 自带组件，不需要安装第三方 Python 库，也不需要执行 `pip install`。

如果电脑已经安装 Python 3，直接双击 `eyecare_202020_v9.pyw` 即可运行。`.pyw` 文件会隐藏命令行窗口，适合日常使用。

## 默认设置

- 工作时长：20 分钟
- 休息时长：20 秒
- 语音模式：Windows 原生 TTS
- 自定义语音文件：空
- 休息锁定方式：全屏置顶遮罩
- 计时按钮：开始 / 暂停 / 继续三种状态合并为同一个按钮
- 试听控制：试听提示 / 暂停试听 / 播放试听 / 结束试听
- 应急解锁：`Ctrl + Alt + U`

默认提示文字：

```text
工作时间到了，请离开屏幕，看向 20 英尺（约 6 米）外的地方，休息一下眼睛。It's time to take a break from work. Please look away from the screen, focus on something 20 feet (about 6 meters) away, and rest your eyes.
```

## 使用方法

1. 打开 `eyecare_202020_v9.pyw`。
2. 填写“工作时长（分钟）”和“休息时长（秒）”。
3. 默认使用 Windows 原生 TTS，此时“语音提示文字”会用于生成语音。
4. 如果选择“使用自定义语音文件”，或点击“浏览”选择本地音频文件，“语音提示文字”会变灰且不可编辑。
5. 点击“试听提示”测试当前语音设置。试听未结束前，“试听提示”会变灰，不能重复点击。
6. 试听中可点击“暂停试听”；暂停后可点击“播放试听”；任何时候都可以点击“结束试听”停止当前试听。
7. 点击“保存设置”保存当前配置，下次启动会自动加载。
8. 保存过设置后，“导入保存设置”按钮会变为可用。
9. 点击计时按钮进入工作倒计时。按钮会根据状态显示“开始”“暂停”或“继续”。
10. 工作倒计时结束后，程序播放提示音，并进入全屏休息遮罩。
11. 休息倒计时结束后，程序自动返回主界面，并开始下一轮工作倒计时。
12. 如需应急解锁，在休息遮罩期间按 `Ctrl + Alt + U`。

## 导入保存设置

“导入保存设置”按钮位于“重置为默认”按钮左边。

第一次使用程序时，如果还没有通过“保存设置”生成有效的 `eyecare_202020_config.txt`，这个按钮会是灰色且不可点击。

保存过设置后，点击“导入保存设置”会打开文件选择窗口。默认会定位到程序目录，并显示保存设置时生成的配置文件。选择文件后，程序会读取其中的工作时长、休息时长、语音模式、自定义音频路径和提示文字，并立即刷新界面倒计时。

点击“重置为默认”不会删除保存设置。只要当前目录里仍有有效的 `eyecare_202020_config.txt`，“导入保存设置”按钮会保持可用；只有第一次使用、或当前目录里没有有效保存设置时，它才会是灰色。

## 重置为默认

点击“重置为默认”后，程序会：

- 停止当前工作倒计时。
- 把工作时长恢复为 20 分钟。
- 把休息时长恢复为 20 秒。
- 把语音模式恢复为 Windows 原生 TTS。
- 清空自定义语音文件路径。
- 恢复默认提示文字。
- 保留已有的 `eyecare_202020_config.txt`。

如果希望下次启动也使用这些默认值，请在重置后点击“保存设置”。

## 自定义语音文件

推荐使用 `.wav` 文件，兼容性最好。

默认情况下，程序会把“语音提示文字”中的内容交给 Windows 原生 TTS 播报。选择自定义语音文件后，程序播放你指定的音频文件，不再读取提示文字，所以提示文字区域会自动变灰并禁止编辑。

程序通过 Windows MCI 控制音频播放，这样才能支持暂停、继续和结束试听。`.mp3`、`.wma` 等格式是否可用取决于当前 Windows 的媒体支持；如果无法播放，请换成 `.wav`，或切回 Windows 原生 TTS。

## 试听控制与休息提示音时长

“试听提示”用于开始试听。试听开始后，该按钮会变灰；试听自然结束或点击“结束试听”后，它会恢复可用。

试听过程中：

- “暂停试听”会暂停当前试听。
- “播放试听”会从暂停位置继续播放。
- “结束试听”会立即停止当前试听。

休息提醒语音必须短于休息时长。程序会尽量读取或生成提示音的实际时长；如果发现提示音时长大于或等于休息时长，会弹窗告知，并在休息结束前提前停止播放。这样可以避免休息结束后提示音仍然继续播放。

## 休息遮罩与应急解锁

休息时，程序会创建全屏置顶遮罩，覆盖桌面并拦截常见关闭操作。遮罩上只显示休息倒计时和护眼提示，不显示应急解锁组合键。

应急解锁组合键是 `Ctrl + Alt + U`。这个提示只在主界面显示。按下后会立即解除休息遮罩，停止当前休息倒计时，并返回主界面；程序不会自动开始下一轮工作倒计时。

本版本已删除系统级键鼠锁定功能，所以不会再出现那个无效选择框。

## 注意事项

- 首次测试建议把休息时长设为 5 秒，确认遮罩、自动返回和应急解锁正常。
- 为避免误锁过久，程序限制休息时长最多为 3600 秒。
- Windows 的 `Ctrl + Alt + Delete` 属于系统安全界面，通常仍可用于紧急处理。
- 语音解锁未加入本版本，因为它需要麦克风权限和常驻语音识别，误识别/漏识别风险更高。

## 可选：打包成 exe

程序本身不需要第三方库。如果希望在没有 Python 的电脑上运行，可以在已安装 Python 的电脑上用 PyInstaller 打包。

安装 PyInstaller：

```powershell
pip install pyinstaller
```

在程序所在目录执行：

```powershell
pyinstaller --onefile --windowed eyecare_202020_v9.pyw
```

打包完成后，生成的 exe 通常位于 `dist` 目录。
