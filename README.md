# 20-20-20 护眼提醒器

一个适用于 Windows 的 20-20-20 护眼提醒工具。默认每工作 20 分钟提醒休息 20 秒，休息时显示全屏置顶遮罩，并可通过 Windows 原生 TTS 或自定义音频播放提醒。

## 下载

不安装 Python 的用户可以在 GitHub Releases 下载便携版压缩包：

- `eyecare_202020_v9_portable.zip`

已安装 Python 3 的用户也可以直接双击运行源码文件：

- `eyecare_202020_v9.pyw`

## 功能

- 20 分钟工作、20 秒休息的默认护眼节奏
- 工作时长和休息时长可自定义
- Windows 原生 TTS 语音提醒
- 支持自定义本地音频文件
- 全屏置顶休息遮罩
- 试听、暂停试听、继续试听、结束试听
- 保存和导入本地设置
- 应急解锁快捷键：`Ctrl + Alt + U`

## 运行环境

- 推荐 Windows 10 或 Windows 11
- 源码版需要 Python 3
- Python 源码只使用标准库和 Windows 自带组件，不需要安装第三方 Python 包
