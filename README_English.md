## Why It Is Called 20-20-20

"20-20-20" comes from a common eye-care habit: after every 20 minutes of screen work, look at something 20 feet away, about 6 meters, for at least 20 seconds. This app uses 20 minutes of work and 20 seconds of rest by default.

## Requirements

Recommended system: Windows 10 or Windows 11.

The program uses only the Python standard library and built-in Windows components. No third-party Python packages are required, and you do not need to run `pip install`.

If Python 3 is already installed, double-click `eyecare_202020_v9.pyw` to run it. The `.pyw` file starts without showing a console window.

## Default Settings

- Work duration: 20 minutes
- Break duration: 20 seconds
- Voice mode: Windows native TTS
- Custom voice file: empty
- Break lock method: full-screen always-on-top overlay
- Timer control: Start / Pause / Resume are combined into one button
- Preview controls: Test Alert / Pause Preview / Play Preview / Stop Preview
- Emergency unlock: `Ctrl + Alt + U`

Default alert message:

```text
工作时间到了，请离开屏幕，看向 20 英尺（约 6 米）外的地方，休息一下眼睛。It's time to take a break from work. Please look away from the screen, focus on something 20 feet (about 6 meters) away, and rest your eyes.
```

## How to Use

1. Open `eyecare_202020_v9.pyw`.
2. Enter the work duration in minutes and the break duration in seconds.
3. By default, Windows native TTS is used, so the alert message box is used to generate speech.
4. If you choose "custom voice file" or select a local audio file with "Browse", the alert message box becomes gray and read-only.
5. Click "试听提示" / "Test Alert" to test the current voice setting. While preview playback is active, this button is disabled and cannot be clicked again.
6. During preview playback, click "暂停试听" / "Pause Preview" to pause. After pausing, click "播放试听" / "Play Preview" to resume. Click "结束试听" / "Stop Preview" to stop the current preview at any time.
7. Click "保存设置" / "Save Settings" to save the current configuration for the next launch.
8. After settings have been saved, "导入保存设置" / "Import Saved Settings" becomes available.
9. Click the timer button to begin the work countdown. The same button changes between "开始" / "Start", "暂停" / "Pause", and "继续" / "Resume".
10. When the work countdown ends, the app plays the alert and enters the full-screen break overlay.
11. When the break countdown ends, the app returns to the main window and starts the next work cycle.
12. For emergency unlock during the break overlay, press `Ctrl + Alt + U`.

## Import Saved Settings

"导入保存设置" / "Import Saved Settings" is placed to the left of "重置为默认" / "Reset to Defaults".

On first use, if no valid `eyecare_202020_config.txt` has been generated by "Save Settings", this button is gray and cannot be clicked.

After settings have been saved, clicking "Import Saved Settings" opens a file selection window. It starts in the program folder and points to the settings file generated by "Save Settings". After you choose a file, the app imports the work duration, break duration, voice mode, custom audio path, and alert message, then refreshes the countdown display.

Clicking "Reset to Defaults" does not delete saved settings. As long as a valid `eyecare_202020_config.txt` still exists in the current folder, "Import Saved Settings" remains enabled. It is disabled only on first use or when no valid saved settings file exists in the current folder.

## Reset to Defaults

After clicking "Reset to Defaults", the app will:

- Stop the current work countdown.
- Restore the work duration to 20 minutes.
- Restore the break duration to 20 seconds.
- Restore the voice mode to Windows native TTS.
- Clear the custom voice file path.
- Restore the default alert message.
- Keep the existing `eyecare_202020_config.txt`.

If you want the next launch to use these default values, click "Save Settings" after reset.

## Custom Voice File

`.wav` is recommended for best compatibility.

By default, the app sends the alert message text to Windows native TTS. After you choose a custom voice file, the app plays the selected audio file instead of reading the text, so the message area automatically becomes gray and read-only.

The app uses Windows MCI for audio playback so preview audio can be paused, resumed, and stopped. Formats such as `.mp3` and `.wma` depend on the media support available on the current Windows system. If a file cannot be played, use `.wav` or switch back to Windows native TTS.

## Preview Controls and Break Alert Duration

"试听提示" / "Test Alert" starts preview playback. After preview starts, that button is disabled. It becomes available again when preview playback ends naturally or when "结束试听" / "Stop Preview" is clicked.

During preview playback:

- "暂停试听" / "Pause Preview" pauses the current preview.
- "播放试听" / "Play Preview" resumes from the paused position.
- "结束试听" / "Stop Preview" immediately stops the current preview.

The break alert audio must be shorter than the break duration. The app tries to read or generate the actual alert duration. If the alert duration is greater than or equal to the break duration, the app shows a warning and stops playback before the break ends. This prevents the alert audio from continuing after the break has already finished.

## Break Overlay and Emergency Unlock

During a break, the app creates a full-screen always-on-top overlay and blocks common close actions. The overlay shows only the break countdown and eye-care prompt. It does not show the emergency unlock hotkey.

The emergency unlock hotkey is `Ctrl + Alt + U`. This hint is shown only in the main UI. Pressing the hotkey immediately removes the break overlay, stops the current break countdown, and returns to the main window. The app will not automatically start the next work cycle.

The system-level keyboard and mouse locking feature has been removed in this version, so the previous ineffective checkbox no longer appears.

## Notes

- For the first test, set the break duration to 5 seconds and confirm that the overlay, automatic return, and emergency unlock work correctly.
- To avoid locking the computer for too long by mistake, the break duration is limited to 3600 seconds.
- `Ctrl + Alt + Delete` is a Windows secure attention shortcut and is usually still available for emergency handling.
- Voice unlock is not included in this version because it would require microphone permission and continuous speech recognition, with higher risk of false triggers or missed recognition.

## Optional: Build an exe

The program itself does not require third-party libraries. If you want to run it on a computer without Python, you can build an exe with PyInstaller on a computer that already has Python installed.

Install PyInstaller:

```powershell
pip install pyinstaller
```

Run this command in the program folder:

```powershell
pyinstaller --onefile --windowed eyecare_202020_v9.pyw
```

After packaging, the generated exe is usually in the `dist` folder.
